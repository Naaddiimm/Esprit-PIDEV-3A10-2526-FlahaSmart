# FlahaSmart

## Overview

This project was developed as part of the PIDEV – 3rd Year Engineering Program at **Esprit
School of Engineering** (Academic Year 2025–2026).
FlahaSmart is a Smart Agriculture Desktop Application designed to help farmers monitor, manage, and optimize agricultural activities using intelligent technologies.

## Tech Stack

* Java
* JavaFX
* MySQL
